# Sträcklabbet för Vilma

En statisk övningssida för reaktionssträcka, bromssträcka och stoppsträcka inför teoriprovet.

## Publicera på GitHub Pages

1. Lägg filerna `index.html`, `styles.css` och `script.js` i ett GitHub-repo.
2. Gå till `Settings` -> `Pages`.
3. Välj `Deploy from a branch`.
4. Välj branch `main` och mappen `/root`.

Sidan kräver inget byggsteg och inga externa bibliotek.
